FontFixer Privacy Policy

Short version: FontFixer never reads, stores, or uploads webpage content. All font configuration stays in your browser. Free use is fully offline — the only network request is optional Pro license activation, which sends your license key and basic browser info to the license server. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

01Data Collection

FontFixer does not collect or store any of the following:

  • Browsing history or URLs visited
  • Page text, images, or content
  • Cookies or tracking identifiers
  • Usage analytics or telemetry

02Permissions

FontFixer uses these permissions only to adjust page fonts:

  • storage — Saves your font preferences locally. No webpage content is stored.
  • scripting — Injects CSS to change page fonts. Does not read page text or data.
  • activeTab — Only accesses the current tab when you interact with the extension.
  • Host access — Lets saved styles be re-applied automatically on sites you have configured (Auto Apply). It never reads or uploads page content.
Host access covers all sites so saved styles can be re-applied on any site you configure — it is never used to read or upload page content.

03Data Storage

All settings are stored locally in your browser using chrome.storage.local. Data is deleted when you uninstall the extension.

04License Activation & Network

Free use works fully offline. If you activate a Pro license, FontFixer sends your license key, a random install identifier, and basic browser info (browser version, language, timezone) to our license server (api.annmax1983.com) to validate the license. No webpage content is ever sent.

05Open Source Fonts

Built-in fonts (Noto Sans, Source Han Sans, Arial) are open-source or system fonts with commercial-use licenses.

06Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them.

07Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.

08Contact

Questions about this policy? Email support@annmax1983.com or open an issue on GitHub.
