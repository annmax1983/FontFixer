# FontFixer

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

快適な閲覧のためにWebページのフォントを最適化する軽量ブラウザ拡張機能です。フォントファミリー、サイズ、テキスト色をワンクリックで変更できます。

> Chromium系ブラウザ対応 · Manifest V3 · 最小限の権限 · トラッキングなし

---

## FontFixerの特長

多くのWebサイトでは、小さくて読みにくい、またはぼやけたフォントが使用されています。FontFixerでは、お好みの書体でWebページのフォントを調整し、フォントサイズを変更し、テキスト色やリンク色をカスタマイズできます — すべてリアルタイムで、ページ再読み込み不要です。

| 特長 | 詳細 |
|-----------|--------|
| 🔤 **ローカルフォント対応** | `queryLocalFonts` APIでデバイスにインストールされたフォントを読み取り |
| ⚡ **リアルタイムプレビュー** | 調整中にすべての変更が即座に適用 — ページ再読み込み不要 |
| 💾 **サイト別記憶** | 異なるWebサイトに異なるフォント設定を保存 |
| ⚙️ **自動適用** | 設定済みサイトへの訪問時に保存済み設定を自動再適用 |
| 🔒 **権限** | `storage`＋`scripting`＋`activeTab`；`<all_urls>`ホストアクセスは設定済みサイトへのフォント注入のみに使用 |

## インストール

1. ブラウザの拡張機能ページを開きます：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. **デベロッパーモード**を有効にします（右上のトグル）
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`font-fixer`フォルダを選択します
4. ツールバーの🔤 FontFixerアイコンをクリックして開始します

---

## 使い方

### フォントを変更する

1. ツールバーのFontFixerアイコンをクリックします
2. ドロップダウンからフォントを選択 — 3つの組み込みフォントが常に利用可能。**🔄**をクリックするとデバイスにインストールされたフォントを読み込めます
3. スライダーでフォントサイズを調整（80%〜160%）
4. オプションで**テキスト色**／**リンク色**にチェックを入れて色を上書き（OFF＝ページの色を変更しない）
5. **適用して保存**をクリック — 設定が即座に適用され、このサイト用に保存されます

### 自動適用

- **自動適用**スイッチをONにすると、そのサイトに訪問するたびに保存済みの設定が自動的に再適用されます
- 自動適用がOFFの場合、設定はポップアップを開いて**適用して保存**をクリックした時のみ適用されます

### リセット

- **リセット**をクリックして、現在のサイトの設定を削除し、元のフォントを復元します

## 動作の仕組み

```
フォントを選択＆設定を調整
       ↓
適用して保存をクリック
       ↓
chrome.scripting.insertCSSでCSSを注入
       ↓
ページのフォントが即座に変更
       ↓
chrome.storage.localに設定を保存
       ↓
（自動適用ON）次回訪問時に自動再適用
```

すべてのスタイル処理はブラウザ内でローカルに実行されます。唯一のネットワークリクエストは**オプション**のものです — Proライセンスキーを有効化する際、FontFixerがライセンスサーバーにキーと基本的なブラウザメタデータ（ブラウザ、言語、タイムゾーン）を送信します。Webページのコンテンツが読み取られたりアップロードされたりすることはありません。

**ローカルフォントアクセスに関する注意：** ローカルフォントはLocal Font Access APIを使用します — マニフェスト権限は不要です。Chromeがランタイム時に権限プロンプトを表示し、APIはユーザークリック時にのみ実行されるため、ポップアップを開いて**🔄更新ボタン**をクリックしてローカルフォントを読み込んでください。フォントの表示名のみが読み取られ、フォントソースファイルは抽出・コピー・アップロードされません。ブラウザ設定でいつでも権限を撤回できます。

**自動適用ルール：** 自動スタイル注入はサイトごとの設定です。ポップアップ内の**自動適用**スイッチをONにすると、そのサイトの設定が訪問ごとに再適用されます。OFFの場合は、**適用して保存**をクリックした時のみ設定が適用されます。

## フォント著作権に関する注意

3つの組み込み書体（Noto Sans、Source Han Sans、Arial）はSIL Open Font Licenseの下で配布されており、追加の許可なく個人利用および商業利用が可能です。

この拡張機能はブラウザ標準APIを通じてローカルデバイスにインストールされたフォントの名前リストを読み取るだけであり、ローカルフォントファイルを抽出、コピー、アップロードすることはありません。システムフォントのすべての権利は、それぞれの著作権者に帰属します。

## プライバシー

- `storage` — フォント設定をローカルに保存します。Webページのコンテンツは保存されません。
- `scripting` — ページのフォントを変更するCSSを注入します。ページテキストやデータは読み取りません。
- `activeTab` — 拡張機能との操作時にのみ現在のタブにアクセスします。
- `<all_urls>` — 設定済みサイトで保存済みフォントスタイルを自動再適用できるようにします。ページコンテンツを読み取ったりアップロードしたりすることはありません。
- **ローカルフォントアクセス** — マニフェスト権限不要。ブラウザプロンプトによるランタイム時のアクセス許可。表示名のみ読み取り、フォントファイルは読み取りません。いつでも撤回可能です。
- トラッキング、アナリティクスなし。唯一のネットワークリクエストはProライセンスキー使用時のライセンス有効化/検証です。

## 著作権に関する免責事項

この拡張機能は、ユーザーの快適な閲覧体験のためにWebページの視覚的なレンダリングスタイルをローカルで調整するだけです。Webサイトのすべてのテキスト、画像、コンテンツの著作権は、オリジナルの発行者に帰属します。ページの表示スタイルを変更しても、ユーザーにWebサイトコンテンツの著作権が付与されるものではありません。ユーザーはWebページ閲覧時に現地の知的財産法に従うものとします。
