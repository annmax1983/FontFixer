# FontFixer
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

快適な閲覧のためにウェブページのフォントを最適化する軽量ブラウザ拡張機能。ワンクリックでフォント、サイズ、テキスト色を変更。

> Chromium ベース · Manifest V3 · 最小権限 · トラッキングなし

---

## 機能

### 🆓 無料版

| 機能 | 説明 |
|------|------|
| 🔤 **フォント選択** | 3つの内蔵フォントまたはデバイスにインストールされた任意のフォント |
| 📏 **フォントサイズ** | 80%〜160%のスライダー調整 |
| 🎨 **テキスト色** | カラーピッカーでカスタマイズ |
| 🔗 **リンク色** | 読みやすさ向上のための個別設定 |
| 🔄 **自動適用** | 設定したサイトでは毎回自動的に設定を再適用 |
| 💾 **自動保存** | サイトごとに設定を永続化（最大5サイト） |

### ⭐ Pro（ライセンス必要）

| 機能 | 説明 |
|------|------|
| ♾️ **無制限の設定** | 無制限のサイトにフォント設定を保存 |
| 📦 **インポート / エクスポート** | 設定をエクスポートし、他のデバイスにインポート |

---

## インストール

1. `chrome://extensions/`を開く
2. **デベロッパーモード**を有効化
3. **パッケージ化されていない拡張機能を読み込む**
4. ツールバーの🔤 FontFixerアイコンをクリック

---

## プライバシー

- 追跡なし、分析なし。唯一のネットワークリクエストはProライセンスキー使用時の認証/検証のみ。
- すべてのデータはブラウザにローカル保存
- `<all_urls>` — 設定したサイトで保存済みのフォントスタイルを自動再適用するため。ページコンテンツの読み取りやアップロードは行いません。
- **ローカルフォントアクセス** — マニフェスト権限は不要。ブラウザの実行時プロンプトで付与。フォントの表示名のみを読み取り、フォントファイルは読み取りません。
