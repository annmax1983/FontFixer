# FontFixer
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款轻量级浏览器扩展，优化网页字体以获得舒适阅读体验。一键更换字体、调整字号和文字颜色。

> 基于 Chromium · Manifest V3 · 最小权限 · 本地处理处理

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 🔤 **字体选择** | 3 种内置字体（Noto Sans、Source Han Sans、Arial）或设备上安装的任意字体 |
| 📏 **字号缩放** | 80% 至 160% 滑动调节 |
| 🎨 **文字颜色** | 取色器自定义文字颜色 |
| 🔗 **链接颜色** | 单独设置链接颜色，提升可读性 |
| 🔄 **作用范围** | 仅当前站点或全局应用 |
| 💾 **自动保存** | 按站点自动持久化设置 |
| ↺ **一键重置** | 即时恢复原始页面字体 |
| 🌍 **6 种语言** | 英文、中文、日文、西班牙文、德文、法文 |

---

## 安装

1. 打开 `chrome://extensions/`
2. 开启**开发者模式**
3. 点击**加载已解压的扩展程序**
4. 点击工具栏中的 🔤 FontFixer 图标

---

## 使用方法

1. 点击 FontFixer 图标
2. 从下拉菜单选择字体（或点击内置字体标签）
3. 滑动调整字号
4. 可选：修改文字和链接颜色
5. 点击 **应用** — 即时生效

### 按站点 vs 全局

- **当前站点**（默认）：设置仅应用于当前网站
- **所有站点**：设置应用于所有网站
- 使用范围按钮切换

---

## 隐私

- `storage` — 本地保存字体偏好，不存储网页内容
- `scripting` — 注入 CSS 更改页面字体，不读取页面文本或数据
- `activeTab` — 仅在点击应用时访问当前标签页
- 无追踪、无分析、无外部连接
